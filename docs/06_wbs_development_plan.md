## 7. 專案管控機制

### 📊 進度報告週期
- **TaskMaster 即時追蹤**: 持續更新 WBS 狀態
- **週報**: 每週五更新專案進度
- **里程碑報告**: 關鍵節點完成時生成詳細報告

### 🔄 變更管控流程
1. **變更請求提交** → 2. **影響評估** → 3. **技術評審** → 4. **批准/拒絕** → 5. **更新 WBS 與 ADR**

**⚠️ 重要備註 - ADR 變更追蹤機制:**
- 所有 WBS 內容的重大變更必須建立對應的 [ADR (架構決策記錄)](./01_adr_template.md)
- 變更類型與 ADR 要求：
  - **技術架構變更** → 必須建立 ADR
  - **任務範圍調整** → 建議建立 ADR
  - **時程或資源調整** → 視影響程度決定
- ADR 編號規則：`ADR-WBS-XXX-[變更主題]`

### ⚖️ 資源分配原則
- **關鍵路徑優先**: 認證 → 自動簽到 → 請假補簽
- **風險緩解優先**: Google API 整合優先處理
- **技能匹配**: 根據專長分配任務
